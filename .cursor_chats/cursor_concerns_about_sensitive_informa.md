```python
# When creating nodes, exclude sensitive keys
```

```python
from llama_index.core.postprocessor.types import BaseNodePostprocessor
```

Looking at the LlamaIndex codebase, there are several ways to control metadata inclusion in LLM context while keeping it available for other purposes:

## **1. Node-Level Metadata Exclusion**

In LlamaIndex, each node has built-in properties to exclude metadata from LLM context:

```python
# When creating nodes, you can specify which metadata keys to exclude
for node in nodes:
    node.excluded_llm_metadata_keys = [
        'file_path', 's3_key', 's3_bucket', 'source_type'
    ]
    node.excluded_embed_metadata_keys = [
        'file_path', 's3_key', 's3_bucket'  # Also exclude from embeddings
    ]
```

## **2. MetadataMode Settings**

LlamaIndex has different metadata modes:

```python
from llama_index.core.schema import MetadataMode

# When creating extractors or processing nodes
extractor = QuestionsAnsweredExtractor(
    questions=3, 
    llm=llm, 
    metadata_mode=MetadataMode.EMBED  # Only use for embeddings, not LLM
)
```

Available modes:
- `MetadataMode.ALL` - Include all metadata
- `MetadataMode.LLM` - Only metadata for LLM context  
- `MetadataMode.EMBED` - Only metadata for embeddings
- `MetadataMode.NONE` - No metadata

## **3. Query Engine Configuration**

The `as_query_engine()` method in `base.py` passes kwargs to `RetrieverQueryEngine.from_args()`, which supports metadata filtering:

```python
# In your RAG service
query_engine = index.as_query_engine(
    similarity_top_k=self.config.similarity_top_k,
    response_mode="tree_summarize",
    verbose=True,
    # Add metadata exclusion
    exclude_llm_metadata_keys=[
        'file_path', 's3_key', 's3_bucket', 'source_type'
    ]
```

## **4. Custom Node Postprocessor (Cleanest Solution)**

Create a postprocessor that strips sensitive metadata before LLM context:

```python
from llama_index.core.postprocessor.types import BaseNodePostprocessor
from llama_index.core.schema import NodeWithScore, QueryBundle
from typing import List, Optional

class MetadataCleanerPostprocessor(BaseNodePostprocessor):
    """Remove sensitive metadata before sending to LLM."""
    
    def __init__(self, keep_keys: List[str] = None):
        self.keep_keys = keep_keys or ['file_name', 'page_label']
    
    def _postprocess_nodes(
        self, 
        nodes: List[NodeWithScore], 
        query_bundle: Optional[QueryBundle] = None
    ) -> List[NodeWithScore]:
        for node_with_score in nodes:
            # Keep original metadata for application use
            original_metadata = node_with_score.node.metadata.copy()
            
            # Create clean metadata for LLM
            clean_metadata = {
                key: value for key, value in original_metadata.items()
                if key in self.keep_keys
            }
            
            # Update node metadata (this affects LLM context)
            node_with_score.node.metadata = clean_metadata
            
            # Store original metadata in a way your app can access if needed
            node_with_score.node.extra_info = original_metadata
            
        return nodes

# Use in query engine
query_engine = index.as_query_engine(
    similarity_top_k=self.config.similarity_top_k,
    response_mode="tree_summarize",
    node_postprocessors=[
        MetadataCleanerPostprocessor(keep_keys=['file_name'])
    ]
)
```
